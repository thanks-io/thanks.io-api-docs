# Remote URL

Add the thanks.io MCP server URL directly to your tools

```
https://docs.thanks.io/mcp
```

# Local Setup

For a ready-to-use MCP server that connects thanks.io to your AI applications, use the following command:

```bash
npx mint-mcp add thanksio
```

# Vibe Coding Websites

Some website development platforms (such as Repllit) won't allow you to set MCP servers or use remote URLs.  You can manually feed any endpoint info into the platform by click 'Copy page' and manually pasting this info into your platform.  The drop down option even provides quick links to add to ChatGPT and Claude.
