# Remote URL

Add the thanks.io documentation MCP server URL directly to your tools to give AI clients access to the thanks.io API docs and endpoint reference.

```
https://docs.thanks.io/mcp
```

# Local Setup

For a ready-to-use documentation MCP server for the thanks.io API, use the following command:

```bash
npx mint-mcp add thanksio
```

# Vibe Coding Websites

Some website development platforms (such as Repllit) will not let you configure MCP servers or use remote MCP URLs. In that case, you can manually copy documentation pages and paste the API details into your platform. The dropdown also includes quick links for ChatGPT and Claude.
