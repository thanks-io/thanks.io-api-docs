Giftcards offer extension features to end users, including gating and scan tracking - for more info visit https://help.thanks.io/sending-mail/mailer-types/gift-cards

## Send a Creative (Recommended)

Design the gift card once as a creative in your [dashboard](https://dashboard.thanks.io/app/creatives). A gift card creative's message carries the gift card brand and amount along with the message and handwriting, so the send only needs the creative's ID and your audience. You don't query brands or pass `giftcard_brand` and `giftcard_amount_in_cents`.

<Steps>
  <Step title="Find the Creative">
    List your complete gift card creatives and note the `id` of the one you want to send. You can also copy the ID from the creative's card menu (**Copy creative ID**) in the dashboard.

    See [List Creatives](/api-reference/endpoint/creatives-library/list-all-creatives) for more info.

  ```bash
  curl -X GET "https://api.thanks.io/api/v2/creatives?mailer_type=giftcard&complete_only=1" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer YOUR_API_KEY"
  ```
  </Step>
  <Step title="Send the Creative">
    Pass the ID as `creative_id` with your recipients. The account is charged for the mailing and for the face value of each gift card.

  ```bash
  curl -X POST "https://api.thanks.io/api/v2/send/giftcard" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -d '{
      "creative_id": "CREATIVE_ID_FROM_PREVIOUS_STEP",
      "recipients": [
        {
          "name": "Jane Doe",
          "address": "456 Another St",
          "city": "Fake City",
          "province": "NY",
          "postal_code": "55555",
          "country": "US"
        }
      ]
    }'
  ```
  </Step>
</Steps>

To check the total first, post the same body to [`POST /estimate/giftcard`](/api-reference/endpoint/estimate/estimate-giftcard). A creative sends exactly as saved, so leave out the image, message, handwriting, and background parameters. See [Send a Creative](/api-reference/send-mailer-usage#send-a-creative) for the full rules.

## Choose a Brand and Amount per Request

To pick the brand and amount in the request instead, query the available options and pass them with the front image and message:

<Steps>
  <Step title="Query the available giftcard brands and amounts">

    See [giftcard brands](/api-reference/endpoint/giftcards/list-brands) for more info.

  ```bash
  curl -X GET "https://api.thanks.io/api/v2/giftcard-brands" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer YOUR_API_KEY"
  ```
  </Step>
  <Step title="Select Giftcard Brand and Amount">
    After querying the available giftcard brands and amounts, select the desired brand and amount for your giftcard.
  </Step>
  <Step title="Send Giftcard">
    Send a giftcard to a recipient via the API.

    See [send-giftcard](/api-reference/endpoint/send-mailer/send-giftcard) for more info.

  ```bash
  curl -X POST "https://api.thanks.io/api/v2/send/giftcard" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -d '{
      "giftcard_brand": "GIFT_CARD_BRAND_ID_FROM_PREVIOUS_STEP",
      "giftcard_amount_in_cents": "GIFT_CARD_AMOUNT_IN_CENTS_FROM_PREVIOUS_STEP",
      "front_image_url": "https://cdn.thanks.io/notecard-inspirations/note1.png",
      "message": "Hey %FIRST_NAME%!,\n\nTHANK YOU for allowing us the opportunity to HELP you with your plan!",
      "recipients": [
        {
          "name": "Jane Doe",
          "address": "456 Another St",
          "city": "Fake City",
          "province": "NY",
          "postal_code": "55555",
          "country": "US"
        }
      ]
    }'
  ```
  </Step>

</Steps>
