---
title: "API Log"
description: "Find the API and Zapier sends made on your account in the dashboard's Audit Log."
---

For debugging API calls, your dashboard keeps a log of API and Zapier sends alongside dashboard actions on your account. Open **Settings → [Audit Log](https://dashboard.thanks.io/app/settings/audit-log)** and use the **Show** filter to narrow the list to one kind of action.
