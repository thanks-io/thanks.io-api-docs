## Common Uses

- Generate a client SDK
- Import the API into Postman or another API client
- Inspect endpoint schemas and request models in one file
- Validate generated tooling against the published contract

## When To Use This Page

If you are learning the API or looking for implementation guidance, start with the [API Reference overview](/api-reference/introduction) or the [Quickstart](/quickstart) instead.

If you already know the workflow you want and need the full spec for tooling, use the link on this page.
