<Update label="January 22" tags={["New Feature"]} >

## Added Duplicate Prevention Toggle

You can now enable or disable **Duplicate Prevention** from the [Mailer Settings](https://dashboard.thanks.io/profile/settings) page.

This setting controls whether duplicate mail pieces are allowed on your account.  
**Note:** This setting does not apply to gift cards.

- **On** — Prevents multiple mail pieces from being sent to the same recipient within a 36-hour window.
- **Off** — Disables duplicate checks. You are responsible for preventing duplicates.

</Update>

<Update label="January 16" tags={["Improvement"]} >

## Added way to preview campaign action

When creating or editing a campaign, you can now preview the mailer that will be sent when a campaign action is triggered. The preview shows the exact mailer, including the selected image template and message template.

If the action uses a mailing list, the first recipient on the list is used for the preview. If the list has no recipients, a placeholder recipient is used instead.
</Update>

<Update label="January 13" tags={["Improvement"]} >

## Added More Order Details in QR Scan Email Notifications

QR scan email notifications now include additional order details to make follow-ups easier and more informative. When you receive a QR scan notification, the email will now show:

- Campaign details — If the order is part of a Campaign, you’ll see the Campaign action type (such as Days After Added, Neighbor Blast, or evenFLOW).

- Mailing list details — If the order is associated with a Mailing List, the Mailing List name will be included.

This added context helps you quickly understand where the scan originated and take the right next steps.

</Update>

<Update label="December 19" tags={["Improvement"]} >

## Added Bulk Actions for Recipients

You can now perform bulk actions on recipients directly from the mailing list page. Select one or more recipients and choose from the following options:

- **Delete** - Remove the selected recipients from the mailing list  
- **Move to Another List** - Transfer the selected recipients to a different mailing list within your account  
- **Send Mailer** - Start the process of sending a mailer to the selected recipients  

## Added Ability to Select the Neighbor Blast Property to Display in Google Street View

When creating a Neighbor Blast campaign using **Dynamic Image Templates** with **Google Street View**, you can now choose which property is displayed on the card:

- **Target (search center) property** — shown by default  
- **Recipient's property**

This setting is available in **Neighbor Blast settings** when creating or editing a campaign.

</Update>

<Update label="November 30" tags={["New Feature"]} >

## evenFLOW Daily Limit Campaign Type

We’ve added a new campaign type — **evenFLOW Daily Limit** — designed to help you send to a fixed number of recipients each day.

- Choose a daily send limit (e.g., 50 mailers/day), and we’ll automatically send that amount from your selected mailing list each day until the list runs out.
- This allows you to pace your outreach and keep engagement steady over time.
- You can also opt to have the campaign loop back to the beginning of the list once it reaches the end, ensuring continuous sending without any manual effort. If this option is turned off, the campaign will pause until new recipients are added.
</Update>

<Update label="November 9" tags={["New Feature"]} >

## Default QR Code Scan Landing Page

We’ve added a **default landing page** that greets your recipient by name, lets them know you’ll reach out soon, and displays your contact info (if set in the Branding Builder).

- If you’re using a **Branding Builder background** with a “Scan Me” image but haven’t set a custom **QR Code URL**, this default page will automatically be used.  
- This ensures recipients always land on a friendly page, even if a QR Code URL wasn’t configured.

#### Optional use
You can also manually apply the default landing page in any **Message Template**:
1. Open the Message Template editor.
2. Click **Use thanks.io Default** under the QR Code settings.
