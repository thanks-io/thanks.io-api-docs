---
title: 'Return Address'
description: 'How is return address set for an order?'
---

The Return Address can be set on a per order basis during a [Send Mailer](/api-reference/send-mailer-usage) request.

The return fields available are:

- `return_name`
- `return_address_line1`
- `return_address_line2`
- `return_city`
- `return_state`
- `return_zip`
- `return_country`
