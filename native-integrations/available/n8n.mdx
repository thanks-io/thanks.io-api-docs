## Overview

Connect thanks.io to your n8n automations.

- npm: https://www.npmjs.com/package/n8n-nodes-thanks-io
- GitHub: https://github.com/thanks-io/n8n-nodes-thanks-io

## Install

In your n8n instance:

1. Open Settings → Community Nodes → Install.
2. Enter: `n8n-nodes-thanks-io` and confirm the install.

## Authentication

Use your thanks.io API key as a Bearer Token credential in n8n.

1. Create or copy your API key in the thanks.io dashboard.
2. In n8n, add new credentials for the Thanks.io nodes and paste the key.

Learn more: [Authentication → Bearer Token](/authentication/bearer-token)

## What you can do

-  Add recipient to an existing Mailing List.  This allows you to easily hook into all thanks.io automations.

Refer to the node descriptions in n8n for exact inputs/outputs and available fields.
